## What is in this build

No code change over 0.1.53. This version exists because verifying the 0.1.53 fix
required a real version change on the server: the positive case ("a genuine
update still raises the banner") cannot be tested without one.

Both directions are now confirmed against the live site:

| Situation | Expected | Observed |
|---|---|---|
| Running 0.1.53, server 0.1.53, worker `waiting` | no banner | no banner |
| Running 0.1.53, server 0.1.54 | banner | banner |

The first row is the case reported from a phone against 0.1.51 and still broken
in 0.1.52. The second confirms the suppression did not simply disable the banner.
