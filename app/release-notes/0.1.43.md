## What is in this build

Two of the three fixes are native-only; the third also affects the website.

- **Android hardware back button** (`35592cb`, native only). Back closed the app
  instead of going up a level — from a project detail page it exited outright.
  Capacitor 8 no longer walks the WebView history on a back press and the app had
  never registered a listener, so the press fell through to the system. Now: an
  active guided tour absorbs the press, otherwise a history step, and `exitApp()`
  only when there is nothing left to go back to. Adds `@capacitor/app` (MIT), so
  `THIRD-PARTY-LICENSES.txt` was regenerated.
- **No bogus "Update verfügbar" after a Play Store update** (`078f233`, native
  only). Capacitor serves the bundled assets from `https://localhost`, so the
  service worker runs in the WebView; on a fresh install the new assets registered
  a new worker while the previous install's controller was still present, which
  raised the banner for assets that were already on screen. The service worker is
  no longer registered in the native shell, where updates arrive through the Play
  Store and precaching local files bought nothing.
- **Info-icon alignment on wrapped hint labels** (`bfbc93d`, **also web**). The
  hint summary centred the ℹ️ against the whole block, so on narrow screens a
  wrapped label pushed the icon ~20 px below the first line. The icon now has its
  own column and stays on the first line, with wrapped lines keeping a straight
  left edge.
